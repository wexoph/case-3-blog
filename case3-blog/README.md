# Кейс-задача №3 — веб-приложение блога

Учебный локально запускаемый блог на Flask и SQLite. Исходный код находится в `app.py`; SQLite-база создаётся при первом запуске в `instance/`.

## Запуск

Требуется Python 3.10+.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000. Для проверки зарегистрируйте два аккаунта: подпишитесь одним на другого, создайте публикацию и проверьте ленту.

## Возможности по заданию

- Регистрация и вход с хешированием паролей.
- Создание публикаций и публичные страницы авторов.
- Подписка и отдельная лента публикаций тех, на кого подписан пользователь.
- Общая лента публичных публикаций.
- Публикация с доступом только после запроса автору; владелец видит входящие запросы.
- Редактирование и удаление собственных записей.
- Теги, поиск по тексту/заголовку и сортировка по дате.
- Комментарии к доступным публикациям.

## Аналитическая часть (7+ пунктов)

1. Роли: гость, зарегистрированный читатель, автор.
2. Основные сущности: пользователь, публикация, подписка, запрос доступа, комментарий.
3. Жизненный цикл публикации: создание → просмотр → изменение/удаление автором.
4. Видимость: публичная либо закрытая до запроса доступа.
5. Социальный граф подписок определяет персональную ленту.
6. Теги и поиск помогают находить тематические записи.
7. Сортировка по времени помогает выбирать актуальные либо ранние публикации.
8. Комментарии обеспечивают обратную связь между читателями и авторами.
9. SQLite упрощает запуск и подходит для демонстрационного объёма данных.

## Ограничения

Это учебный прототип: нет CSRF-защиты, восстановления доступа, API, уведомлений и промышленной настройки. Запрос на закрытый материал отображается владельцу; выдача доступа реализована как подтверждение факта запроса, а не отдельная сложная система разрешений. Стандартный секретный ключ предназначен только для локального запуска. Точный исходный текст методички недоступен в переданном фрагменте разговора; пункты покрытия составлены по заданным требованиям.
